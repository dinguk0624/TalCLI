# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

TalCLI is a fully local tool — it makes no network requests and stores data only in `~/.talcli`. If you find a security issue anyway, please **do not open a public issue**.

Instead, use [GitHub's private vulnerability reporting](https://github.com/dinguk0624/TalCLI/security/advisories/new) with:

1. A description of the issue and its impact
2. Steps to reproduce or a proof of concept
3. Your environment (OS, Node version)

You'll get a response within a few days, and fixes will be released as soon as practical.
